# Mock claims: what is made up and where the photos come from

Every claim in this folder is invented for the demo. Names, policies, vehicles,
amounts, dates and documents are fiction. Each folder's `provenance.json` says
in one line what the claim is for; the screen shows "Mock claim (made up for the
demo)" on the card.

## Photographs

External image sites (Wikimedia Commons included) are not reachable from the
build environment, so the photos are reused from the earlier prototype's
evaluation set and from the Meridian sample claims. Before any external use,
confirm the licence of each Wikimedia file on its Commons file page.
